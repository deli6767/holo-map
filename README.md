# HOLOMAP

A sci-fi holographic mountain projector you can play in the browser. Zoom around a glowing terrain, plan a route, then sneak the little gold figure into a hostile outpost.

**Play it:** [https://deli6767.github.io/holo-map/](https://deli6767.github.io/holo-map/)

## Mission

Infiltrate the red enemy base, grab all four intel/crates, and get back to the green **extraction** pad without being seen.

- Patrolling guards have **vision cones** on the ground. Stay in a cone for a moment and you are **DETECTED** — you lose a life and reset to extraction.
- You have **3 lives**. Walk over loot (or press **E**) to pick it up. The HUD tracks `LOOT X/4`.
- Walls block movement; use the **gate**.
- Extract with all loot for **MISSION COMPLETE**.
- **Restart mission** starts the run over on the same terrain. **New terrain** (or **R**) builds a fresh mountain and relocates the base.

## Controls

| Input | Action |
| --- | --- |
| Left-drag | Orbit |
| Scroll / pinch | Zoom |
| Right-drag | Draw a planning path (arrow on release) |
| WASD / arrows | Move the figure |
| Click in **Move** mode | Walk to that point |
| E | Pick up nearby loot |
| 1–4 | View / Draw / Place enemy / Move |
| Z | Undo last path |
| R | New terrain |

On a phone, turn on **Draw** to trace a path with one finger, and use the on-screen stick to move. **Place enemy** still drops manual red markers if you want extra pins on the map.

Just want to look around? Stay in **View**, zoom, and draw routes on the mountains — the projector works as a holomap even if you ignore the mission.
